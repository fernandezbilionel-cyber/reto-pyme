# El Fenix RD

Tarea individual: Hackeando el Futuro de una Pyme

## Que es
Una pagina web de una pyme dominicana (Tostaduria El Fenix RD) que fue borrada digitalmente y renace con nueva imagen.

## Paginas
- index.html: Historia del misterio
- servicios.html: Servicios reinventados
- contacto.html: Pruebas del incidente y contacto

## Tecnologias usadas
- HTML
- CSS
- JavaScript

## Funciones
- Pantalla de error que se quita con un clic
- Chatbot llamado FenixBot
- Codigo secreto (escribir FENIX)
- Modo oscuro y claro
- Cotizador de pedidos
- Mapa de ubicacion
